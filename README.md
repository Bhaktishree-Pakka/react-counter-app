# React Counter App

A simple and interactive counter application built using React and Vite. This project demonstrates the use of React Hooks (`useState`) for state management.

---

## 🚀 Live Demo

https://react-counter-app-sage.vercel.app

---

## ✨ Features

* ➕ Increment counter
* ➖ Decrement counter
* 🔄 Reset counter
* ⚡ Fast performance using Vite
* 🎯 Clean and minimal UI

---

## 🛠️ Tech Stack

* React
* Vite
* JavaScript
* CSS

## ⚙️ Installation & Setup

1. Clone the repository:

```
git clone https://github.com/Bhaktishree-Pakka/react-counter-app.git
```

2. Navigate to the project folder:

```
cd react-counter-app
```

3. Install dependencies:

```
npm install
```

4. Run the development server:

```
npm run dev
```
